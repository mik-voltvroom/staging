# Bijdragen aan VVOS

1. Maak een branch vanaf `main`.
2. Werk per domein en houd commits klein.
3. Voeg of actualiseer documentatie bij functionele wijzigingen.
4. Voer `npm run check` uit.
5. Gebruik geen productiegegevens in screenshots, tests of fixtures.
6. Beschrijf in de pull request: doel, wijziging, risico, testresultaat en rollback.
